Elleven

Desenvolvedora Fullstack

Outubro de 2021 - Julho de 2022

Desenvolvi a implementação do Pix como um novo meio de pagamento para passagens de ônibus. Para isso, foi necessária a integração com os serviços de um banco por meio de uma nova API em Node.js, que orquestrou a comunicação entre a API de vendas (Laravel) e a API de Pix do banco. Também atuei nas alterações do front-end (Angular) para viabilizar a geração da passagem com o novo meio de pagamento. Na primeira versão da funcionalidade, o QR Code era disponibilizado ao cliente por meio de impressão.

Atuei na solução de um problema crítico de negócio: agências em localidades rurais enfrentavam limitações para depositar a receita das vendas devido a restrições impostas pelos correspondentes bancários. Para contornar essa limitação, desenvolvi um sistema que permitia aos agentes quitarem os montantes devidos por meio de boletos bancários de menor valor. Essa aplicação consiste em uma API em Node.js que, assim como no sistema de Pix, conecta a API principal (Laravel) à API do banco e gera os boletos sob demanda, garantindo a conciliação dos pagamentos. Também implementei as alterações necessárias no front-end (Angular) para que os agentes pudessem gerenciar a geração dos boletos e acompanhar o status de cada pagamento em tempo real.
